# Dataset:
- 60.000 URLs.
- 31.641 clasificadas como phishing.
- 28.359 clasificadas como legítimas.
- Sin URLs duplicadas.
- Hay 2 filas con valores faltantes en cinco características.
- Algunas características presentan valores extremos.
- domain_age y ttl contienen valores -1.
